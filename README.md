## 💡 How to Use Monet

Once you launch the app, you see a clean workspace. The interface allows you to type natural language commands. 

### Create a Project
Start a new project by clicking the button in the top left corner. You can import existing video files or start from a blank canvas for design work.

### Use AI Agents
The software uses agents to process your requests. Type a prompt in the text box at the bottom of the window. For example, you can write "Remove the background from this video" or "Create a thumbnail with a dark blue theme." The agent analyzes your instruction and performs the task automatically.

### Search and Organize
The app includes semantic search. You can search for specific elements inside your project by typing descriptions. If you need a clip where a person walks, type that phrase. Monet finds the relevant sections without requiring manual tags.

## 💬 Frequently Asked Questions

**Does Monet require an internet connection?**
The software needs a connection to reach the AI models. Once the agents receive your prompts, the local processing handles the heavy lifting.

**Is my data private?**
Monet stores all project files on your computer. No files leave your device unless you share them or send prompts to an AI service provider.

**How do I update the software?**
When a new version exists, the app notifies you. Visit the download page again to get the latest file and run the installer. The update process keeps your project files intact.

**Can I undo my mistakes?**
Yes. Use the standard keyboard shortcut Control + Z to reverse your last action. The app maintains a history of changes for every project.

## 🚩 Troubleshooting

If you encounter issues, try these steps first:

1. Restart the application.
2. Check for an active internet connection.
3. Ensure your firewall permissions allow the app to communicate with external AI servers.
4. Verify that you have enough empty disk space for video rendering.

If the app freezes, stop the current task using the red square button in the interface. Clear the cache folder in your settings if rendering errors occur repeatedly.
